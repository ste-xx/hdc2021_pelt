HDC2021 — In-Browser Image Deblurring

Mixed-Scale Dense CNN deblurring for the Helsinki Deblur Challenge 2021. Upload a blurred TIFF (16-bit) or PNG image, select the blur category, and run the neural network entirely in your browser using TensorFlow.js.

How to use: Upload a blurred image from the HDC2021 dataset (16-bit TIFF or PNG), choose the matching blur category, then click Deblur Image. All computation runs locally — nothing is sent to a server. For best results use the original 16-bit TIFF files; 8-bit PNGs are automatically scaled to the expected 16-bit range. Images larger than 600 px on the longest side are resized before processing to limit memory use.

Requirements: The model files must be present under models/. Run python convert_models.py once if they are missing, then serve the directory with a local HTTP server (e.g. python -m http.server 8000) and open http://localhost:8000.
